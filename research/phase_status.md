# Phase completion ledger

| Requested phase | Completed work | Remaining empirical requirement |
|---|---|---|
| 1 Audit | Repository source/artifact inventory, defect and claim audit | Validate all GPU-specific paths after corrections |
| 2 Literature | Primary-source targeted review, direct novelty overlaps identified | Exhaustive venue/full-text reproduction search |
| 3 Contribution | Preservation-aware research question and label-free closed loop | Demonstrate added value over fixed/outcome routers |
| 4 Benchmark | Schema, independent annotation protocol, group isolation/export/seal tools | Collect/annotate balanced natural dataset; rights review |
| 5 Models | Offline GBM inspected/reproduced; synthetic shift experiment; CPU training config; LoRA quarantined | Natural labels and validated GPU trainer before SFT/LoRA comparisons |
| 6 Baselines | Original/detector/fixed/random/type/no-verifier/full protocol arms | Released authentic detector/mitigation runs, learned outcome-router baseline |
| 7 Metrics | Detection, ECE/Brier, selective and preservation-aware repair scorers | Official benchmark-specific scorers on proper generated responses |
| 8 Ablation | Executable config generator; no-diagnosis data removal; matched encoder comparison | Natural full-component ablation runs |
| 9 Generalization | Synthetic count-pattern shift exposes shortcut failure | Cross-VLM and cross-dataset natural tests |
| 10 Failures | 67-case pending review queue and blinded review protocol | At least 50 actual human inspections |
| 11 Calibration | Raw reliability/risk–coverage and disjoint-fit calibration code | Sealed calibration/test evaluation and formal guarantees if sought |
| 12 Statistics | Paired image-cluster bootstrap/randomization; explicit denominators | Powered preregistered primary repair experiment, seed variability |
| 13 Efficiency | Actual API usage/service-time smoke logs and client-RSS sampler | Matched-quality end-to-end cost, memory and cost/1000 estimates |
| 14 Figures | Matched detection, raw calibration, risk–coverage, synthetic shift, architecture/taxonomy, smoke telemetry | Repair-reduction/full ablation figures need actual labels/outcomes |
| 15 Main table | Reproducible same-cohort table plus full-system N/A matrix | Populate missing system arms from independent evaluation |
| 16 Paper | IEEE-style audit/protocol paper, archived old draft | TeX compile/page check; complete empirical paper after P0 experiments |
| 17 Claim audit | Source-mapped supported/unsupported claim table | Update only with new verifiable artifacts |
| 18 Reproduction | Root config/scripts/env/docs, input/output hashes, record/replay | Fresh-machine CI, pinned model revisions and release licenses |
| 19 Review | Three clearly labeled simulated reviewer perspectives + roadmap | Independent external peer review |

This ledger deliberately does not equate a config, mock test or example trace
with a completed experiment. The project is scientifically stronger because
unsupported claims were removed and falsifying controls were added; it is not
declared publication-ready.
